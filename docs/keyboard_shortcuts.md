# キーボードショートカット操作ガイド (Keyboard Shortcuts)

LocalBan では、マウスを使わずにキーボードのみでカード作成から入力、保存、Markdown の編集・プレビュー切り替え、ボード内の移動まで素早く行えるよう、包括的なキーボードショートカット体系を備えています。

いつでもボード上で <kbd>?</kbd>（<kbd>Shift</kbd> + <kbd>/</kbd>）を押すか、画面右上の「**ショートカット**」ボタンをクリックすることで、画面上にショートカット一覧を確認できます。

---

## 1. カード作成・保存フロー

カードのアイデア出しやタスクの書き出しを中断せず、高速に入力・保存できるように設計されています。

| ショートカットキー (Win) | ショートカットキー (Mac) | 操作内容 | 備考 |
| :--- | :--- | :--- | :--- |
| <kbd>c</kbd> または <kbd>n</kbd> | <kbd>c</kbd> または <kbd>n</kbd> | **カード追加を開始** | 現在フォーカス中（未選択時は先頭）のリストで入力フォームを開き、タイトル入力欄に自動フォーカスします。 |
| <kbd>1</kbd> 〜 <kbd>9</kbd> | <kbd>1</kbd> 〜 <kbd>9</kbd> | **指定リストでカード追加** | 左から 1 番目〜 9 番目のリストを直接指定してカード追加フォームを開きます。 |
| <kbd>Enter</kbd> | <kbd>Return</kbd> | **保存して連続作成** | カードを保存し、フォームを開いたまま次のカードタイトルを入力できます（連続作成対応）。 |
| <kbd>Ctrl</kbd> + <kbd>Enter</kbd> | <kbd>Cmd</kbd> + <kbd>Return</kbd> | **保存して終了** | カードを保存し、カード追加フォームを閉じます。 |
| <kbd>Shift</kbd> + <kbd>Enter</kbd> | <kbd>Shift</kbd> + <kbd>Return</kbd> | **保存して詳細を開く** | カードを保存してフォームを閉じ、**そのまま作成したカードの詳細モーダルを開きます**（説明や期限、チェックリストを続けて入力したい場合に最適です）。 |
| <kbd>Escape</kbd> | <kbd>Escape</kbd> | **キャンセル** | 入力内容を破棄し、カード追加フォームを閉じます。 |

> [!NOTE]
> **日本語入力（IME）保護**  
> 日本語入力時の変換確定操作（<kbd>Enter</kbd>）でカードが誤送信されないよう、文字変換中は送信処理が発火しない安全設計となっています。

---

## 2. ボードナビゲーション & カード選択

マウス操作なしでリスト間・カード間を巡回できます。

| ショートカットキー | 操作内容 | 備考 |
| :--- | :--- | :--- |
| <kbd>←</kbd> / <kbd>→</kbd> | **リスト（カラム）の切り替え** | 左右のアクティブなリストを切り替えます。画面外のリストへ移動した際も自動でスクロール追従します。 |
| <kbd>↑</kbd> / <kbd>↓</kbd> | **リスト内のカード選択移動** | 現在のリスト内でカードを上下に選択移動します。端に到達した場合はブラウザの標準スクロールを妨げません。 |
| <kbd>Enter</kbd> または <kbd>Space</kbd> | **カード詳細を開く** | キーボードで選択中のカードの詳細モーダルを開きます。 |
| <kbd>Escape</kbd> | **選択解除** | カードの選択ハイライトを解除します。 |
| <kbd>?</kbd> | **ヘルプ表示** | ショートカット一覧モーダルを表示します。 |

---

## 3. カード詳細モーダル内操作

カード詳細モーダルが開いている際、マウスで小さなアイコンをクリックすることなく各項目を操作できます。

| ショートカットキー (Win) | ショートカットキー (Mac) | 操作内容 | 備考 |
| :--- | :--- | :--- | :--- |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> | **説明文「編集 ⇄ プレビュー」切替** | GitHub 準拠のショートカットです。説明欄の入力中・プレビュー確認中のどちらでもトグル切り替えできます。編集に戻った際は自動でテキストエリアにフォーカスします。 |
| <kbd>Ctrl</kbd> + <kbd>Enter</kbd> | <kbd>Cmd</kbd> + <kbd>Return</kbd> | **説明文を保存** | 説明文の編集内容を保存確定します（編集モード・プレビューモードどちらからでも実行可能）。 |
| <kbd>e</kbd> | <kbd>e</kbd> | **説明文の編集モード開始** | 説明欄を「編集」モードに切り替え、テキストエリアに直接フォーカスします。 |
| <kbd>d</kbd> | <kbd>d</kbd> | **期限日（Due Date）にフォーカス** | 期限日入力フィールドにフォーカスし、カレンダーピッカーを展開します。 |
| <kbd>t</kbd> または <kbd>-</kbd> | <kbd>t</kbd> または <kbd>-</kbd> | **チェックリスト追加** | チェックリストの新規追加フォームを開いてタイトル入力欄にフォーカスします。 |
| <kbd>c</kbd> | <kbd>c</kbd> | **カード複製ダイアログ表示** | カード複製セクションを展開します。 |
| <kbd>a</kbd> | <kbd>a</kbd> | **カードをアーカイブ** | カードをアーカイブに退避し、モーダルを閉じます。 |
| <kbd>Escape</kbd> | <kbd>Escape</kbd> | **段階的キャンセル / 閉じる** | 画像プレビュー表示中はその解除、テキスト入力中はフォーカス解除（blur）、それ以外では詳細モーダル自体を閉じます。 |

※ <kbd>e</kbd> / <kbd>d</kbd> / <kbd>t</kbd> / <kbd>c</kbd> / <kbd>a</kbd> などの単一キーショートカットは、テキストボックス等への文字入力中には誤動作しないよう制御されています。

## 4. Markdown 装飾ショートカット（説明欄編集中）

説明欄の編集中に利用できる Markdown フォーマットおよび Qiita 互換ノート記法（`:::note`）のショートカット一覧です。  
詳細な記法仕様については [Markdown記法・ショートカットキー対応表 (markdown_shortcuts.md)](markdown_shortcuts.md) をご覧ください。

| 機能 | ショートカット (Win) | ショートカット (Mac) | 記法 |
| :--- | :--- | :--- | :--- |
| **太字** | <kbd>Ctrl</kbd> + <kbd>B</kbd> | <kbd>Cmd</kbd> + <kbd>B</kbd> | `**太字**` |
| **斜体** | <kbd>Ctrl</kbd> + <kbd>I</kbd> | <kbd>Cmd</kbd> + <kbd>I</kbd> | `*斜体*` |
| **取り消し線** | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd> | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd> | `~~取り消し線~~` |
| **インラインコード** | <kbd>Ctrl</kbd> + <kbd>E</kbd> | <kbd>Cmd</kbd> + <kbd>E</kbd> | `` `コード` `` |
| **コードブロック** | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd> | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd> | ```` ``` ```` |
| **リンク挿入** | <kbd>Ctrl</kbd> + <kbd>K</kbd> | <kbd>Cmd</kbd> + <kbd>K</kbd> | `[テキスト](url)` |
| **Qiitaノート (info)** | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>1</kbd> | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>1</kbd> | `:::note info` |
| **Qiitaノート (warn)** | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>2</kbd> | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>2</kbd> | `:::note warn` |
| **Qiitaノート (alert)** | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>3</kbd> | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>3</kbd> | `:::note alert` |
