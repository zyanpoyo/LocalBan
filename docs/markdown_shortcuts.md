# Markdown記法・ショートカットキー対応表

LocalBan のカード詳細画面にある「**説明**」欄（Markdown入力）で利用できるキーボードショートカット、フォーマットツールバー、および Qiita 互換の `:::note` 記法のリファレンスです。

---

## ⌨️ ショートカットキー対応表

カードを開いた際の説明欄は、文章を読みやすい「**プレビュー**」モードがデフォルトです。  
プレビュー領域の**ダブルクリック**（未入力時はシングルクリックでも可）、<kbd>e</kbd> キー、<kbd>Ctrl + Shift + P</kbd>、または「**編集**」タブから編集モードへ切り替わり、説明欄が「**編集**」モードでフォーカスされている際、以下のショートカットキーを使用できます。  
（※日本語IMEの変換確定操作と競合しないよう、文字変換中はショートカットが発火しない安全設計になっています）

### 1. モード切替・保存・基本操作

| 機能 | ショートカットキー (Windows) | ショートカットキー (Mac) | 挙動 |
| :--- | :--- | :--- | :--- |
| **集中執筆（Zen）モード切替** | `Ctrl + Shift + F` | `Cmd + Shift + F` | サイドバー等を一時的に隠し、説明欄を画面近くまで拡大します。集中モード中は「プレビュー / 分割（左右2ペイン） / 編集」の3モード切替と、見出し（`H1`〜`H3`）を抽出する目次アウトラインパネルが利用できます。 |
| **編集 ⇄ プレビュー切替** | `Ctrl + Shift + P` | `Cmd + Shift + P` | GitHub準拠。プレビュー表示と編集モードをトグル切り替えします。編集切替時は自動フォーカス。 |
| **説明文を保存してプレビューに戻る** | `Ctrl + Enter` | `Cmd + Return` | 説明文の編集内容を保存確定し、プレビューモードへ戻ります。 |

| 機能 | ショートカットキー (Windows) | ショートカットキー (Mac) | 挿入・変換される記法 | テキスト選択時の挙動 |
| :--- | :--- | :--- | :--- | :--- |
| **太字 (Bold)** | `Ctrl + B` | `Cmd + B` | `**太字**` | 選択範囲を `**` で囲む（既に囲まれている場合は解除） |

| **リンク (Link)** | `Ctrl + K` | `Cmd + K` | `[リンクテキスト](url)` | ・URL（`http://` / `https://`）を選択中：`[リンクテキスト](選択URL)` に変換しテキスト部分を選択<br>・通常テキストを選択中：`[選択テキスト](url)` に変換し `url` 部分を選択 |

### 2. Qiita互換 ノート（コールアウト）記法

Qiita で採用されている3種類のノート記法（`info` / `warn` / `alert`）に対応しています。

| 種類 | ショートカットキー (Windows) | ショートカットキー (Mac) | 挿入される記法 | プレビュー表示スタイル |
| :--- | :--- | :--- | :--- | :--- |
| **補足説明 (Note Info)** | `Ctrl + Shift + 1` | `Cmd + Shift + 1` | `:::note info`<br>`インフォメーション`<br>`:::` | 🟢 緑色ボックス ＋ チェックアイコン<br>（※ `info` は省略して `:::note` のみでも可） |
| **警告 (Note Warn)** | `Ctrl + Shift + 2` | `Cmd + Shift + 2` | `:::note warn`<br>`警告`<br>`:::` | 🟡 黄色ボックス ＋ 警告アイコン |
| **強い警告 (Note Alert)** | `Ctrl + Shift + 3` | `Cmd + Shift + 3` | `:::note alert`<br>`より強い警告`<br>`:::` | 🔴 赤色ボックス ＋ アラートアイコン |

---

## 📝 Qiita互換ノート記法の記述例

ノートブロックの内部では、通常の Markdown（太字、リンク、箇条書き、インラインコードなど）もそのまま使用できます。

### 補足説明（`info` / 省略可）
```markdown
:::note info
インフォメーション
infoは省略可能です。
:::

:::note
`info` を省略した場合もインフォメーションとして表示されます。
:::
```

### 警告（`warn`）
```markdown
:::note warn
警告
○○に注意してください。
:::
```

### 強い警告（`alert`）
```markdown
:::note alert
より強い警告
○○しないでください。
:::
```

## 🧰 フォーマットツールバーとヘルプ表示

説明欄の「**編集**」および「**分割**」モード上部には、マウス操作でも素早く記法を挿入できる**フォーマットツールバー**が備わっています。

1. **ワンクリック装飾・構造化挿入**:
   - **構造化**: 見出し（`H1` / `H2` / `H3`）、引用（`> `）、区切り線（`---`）、テーブル（3列テンプレート）
   - **インライン・リスト・ノート**: 太字、斜体、取り消し線、インラインコード、コードブロック、リンク、箇条書き、チェックボックス、`:::note`（`info` / `warn` / `alert`）
   - 各アイコンボタンをクリックすると、対応するショートカットキーと同じ動作（選択範囲の囲み・トグル解除・テンプレート挿入）が行われます。
2. **ホバーでショートカット確認**:
   - 各ボタンにマウスカーソルを合わせると、ツールチップで機能名とショートカットキー（例：`太字 (Ctrl+B)`）が表示されます。
3. **「ショートカット」ヘルプポップオーバー**:
   - ツールバー右端の「**`?` ショートカット**」ボタンをクリックすると、編集画面を離れることなくショートカットキー対応表をポップオーバーで確認できます。

## 🖥️ 集中執筆（Zen）モードと長文サポート

長文の仕様メモや議事録などを快適に入力したいときは、説明欄ヘッダーの「**集中モード**」ボタン（または `Ctrl + Shift + F`）から集中執筆モードへ切り替えられます。

1. **エディタ領域の最大化**:
   - モーダルを画面近くまで拡大し、右サイドバーや下部セクション（ラベル・チェックリスト・添付ファイル）を一時的に隠して、説明欄の編集に集中できるレイアウトに変化します。
   - 1画面表示（編集・プレビュー）では、背景枠を広げつつ本文を読みやすい中央幅に整えて表示します。
2. **左右2分割（Split View）**:
   - 集中モード時は「**プレビュー**」「**分割**」「**編集**」の3モードを切り替えられ、左ペインで Live Preview 編集しながら右ペインでリアルタイムの全体プレビューを確認できます。
3. **見出しアウトライン（目次）サイドパネル**:
   - 集中モード左側の開閉可能な目次パネルに、本文中の見出し（`#` 〜 `###`）がリアルタイム抽出されます。見出しをクリックすると該当行へスクロール＆カーソル移動します。
4. **安全な段階的 `Escape` 解除**:
   - 集中モード中に `Escape` キーを押すと、いきなりモーダルを閉じず「エディタフォーカス解除 → 集中モード解除（通常モーダル復帰） → モーダル終了」の順で段階的に戻ります。
