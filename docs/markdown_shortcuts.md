# Markdown記法・ショートカットキー対応表

LocalBan のカード詳細画面にある「**説明**」欄（Markdown入力）で利用できるキーボードショートカット、フォーマットツールバー、および Qiita 互換の `:::note` 記法のリファレンスです。

---

## ⌨️ ショートカットキー対応表

説明欄が「**編集**」モードでフォーカスされている際、以下のショートカットキーを使用できます。  
（※日本語IMEの変換確定操作と競合しないよう、文字変換中はショートカットが発火しない安全設計になっています）

### 1. モード切替・保存・基本操作

| 機能 | ショートカットキー (Windows) | ショートカットキー (Mac) | 挙動 |
| :--- | :--- | :--- | :--- |
| **編集 ⇄ プレビュー切替** | `Ctrl + Shift + P` | `Cmd + Shift + P` | GitHub準拠。編集モードとプレビュー表示をトグル切り替えします。編集復帰時は自動フォーカス。 |
| **説明文を保存** | `Ctrl + Enter` | `Cmd + Return` | 説明文の編集内容を保存確定します（編集・プレビュー両モードで有効）。 |

---

### 2. テキスト装飾・リンク・コード

| 機能 | ショートカットキー (Windows) | ショートカットキー (Mac) | 挿入・変換される記法 | テキスト選択時の挙動 |
| :--- | :--- | :--- | :--- | :--- |
| **太字 (Bold)** | `Ctrl + B` | `Cmd + B` | `**太字**` | 選択範囲を `**` で囲む（既に囲まれている場合は解除） |
| **斜体 (Italic)** | `Ctrl + I` | `Cmd + I` | `*斜体*` | 選択範囲を `*` で囲む（既に囲まれている場合は解除） |
| **取り消し線 (Strikethrough)** | `Ctrl + Shift + X` | `Cmd + Shift + X` | `~~取り消し線~~` | 選択範囲を `~~` で囲む（既に囲まれている場合は解除） |
| **インラインコード (Inline Code)** | `Ctrl + E` | `Cmd + E` | `` `コード` `` | 選択範囲を `` ` `` で囲む（既に囲まれている場合は解除） |
| **コードブロック (Code Block)** | `Ctrl + Shift + K`<br>*(または `Ctrl + Shift + C`)* | `Cmd + Shift + K`<br>*(または `Cmd + Shift + C`)* | ```` ``` ````<br>`コード`<br>```` ``` ```` | 選択範囲をコードブロックで囲む（前後に改行を自動補完） |
| **リンク (Link)** | `Ctrl + K` | `Cmd + K` | `[リンクテキスト](url)` | ・URL（`http://` / `https://`）を選択中：`[リンクテキスト](選択URL)` に変換しテキスト部分を選択<br>・通常テキストを選択中：`[選択テキスト](url)` に変換し `url` 部分を選択 |

### 2. Qiita互換 ノート（コールアウト）記法

Qiita で採用されている3種類のノート記法（`info` / `warn` / `alert`）に対応しています。

| 種類 | ショートカットキー (Windows) | ショートカットキー (Mac) | 挿入される記法 | プレビュー表示スタイル |
| :--- | :--- | :--- | :--- | :--- |
| **補足説明 (Note Info)** | `Ctrl + Shift + 1` | `Cmd + Shift + 1` | `:::note info`<br>`インフォメーション`<br>`:::` | 🟢 緑色ボックス ＋ チェックアイコン<br>（※ `info` は省略して `:::note` のみでも可） |
| **警告 (Note Warn)** | `Ctrl + Shift + 2` | `Cmd + Shift + 2` | `:::note warn`<br>`警告`<br>`:::` | 🟡 黄色ボックス ＋ 警告アイコン |
| **強い警告 (Note Alert)** | `Ctrl + Shift + 3` | `Cmd + Shift + 3` | `:::note alert`<br>`より強い警告`<br>`:::` | 🔴 赤色ボックス ＋ アラートアイコン |

---

## 📝 Qiita互換ノート記法の記述例

ノートブロックの内部では、通常の Markdown（太字、リンク、箇条書き、インラインコードなど）もそのまま使用できます。

### 補足説明（`info` / 省略可）
```markdown
:::note info
インフォメーション
infoは省略可能です。
:::

:::note
`info` を省略した場合もインフォメーションとして表示されます。
:::
```

### 警告（`warn`）
```markdown
:::note warn
警告
○○に注意してください。
:::
```

### 強い警告（`alert`）
```markdown
:::note alert
より強い警告
○○しないでください。
:::
```

## 🧰 フォーマットツールバーとヘルプ表示

説明欄の「**編集**」モード上部には、マウス操作でも素早く記法を挿入できる**フォーマットツールバー**が備わっています。

1. **ワンクリック装飾・挿入**:
   - 各アイコンボタンをクリックすると、対応するショートカットキーと同じ動作（選択範囲の囲み・トグル解除・テンプレート挿入）が行われます。
2. **ホバーでショートカット確認**:
   - 各ボタンにマウスカーソルを合わせると、ツールチップで機能名とショートカットキー（例：`太字 (Ctrl+B)`）が表示されます。
3. **「`?`」ショートカット一覧ポップオーバー**:
   - ツールバー右端の「**`?`**」ボタンをクリックすると、編集画面を離れることなくショートカットキー対応表をポップオーバーで確認できます。
