使い方 プライバシーポリシー
インターネット接続不要 アカウント登録不要 Windows 11 / 10 対応

自分のパソコン内だけで完結するタスク管理ボード

作成したリストやカード、添付画像はすべてお使いのパソコン内に自動で保存されます。

完全オフライン保存

外部への通信は一切行いません。業務のメモや個人のタスクも安心して記録できます。

素早いキーボード操作

マウスでのドラッグ移動だけでなく、キーボードだけでもカードの追加・移動が完結します。

自動バックアップ搭載

アプリ起動時に1日1回自動でバックアップを作成。手動でのファイル書き出し・復元にも対応しています。

1. ボードとカードの基本操作

リスト（列）の操作

  • 右端の「＋ リストを追加」から新しい列を作成
  • リスト名をクリックしてタイトルを直接変更
  • リスト上部のドラッグ操作で左右の並び順を変更
  • リストを削除しても、中のカードは消えずに自動で「アーカイブ」へ移動

カードの操作

  • 各リスト下の「＋ カードを追加」または C キーで作成
  • ドラッグ＆ドロップで上下の並び替えや別リストへの移動
  • カードをクリック（または選択して Enter）で詳細画面を表示
  • 詳細画面の「複製」から、内容・チェックリスト・画像ごとコピー可能

2. カード詳細で使える機能

ラベル・チェックリスト

  • 色分けされたラベルを複数付けてタスクを分類
  • 複数のチェックリストを追加し、達成率をバーで視覚的に確認

画像添付・カバー画像

  • ファイルのドラッグ＆ドロップ、またはコピーした画像の貼り付け（Ctrl + V）で添付
  • お気に入りの画像をカードの「カバー画像」に設定可能

期限（日時設定）

  • 残り時間や完了状態に応じてバッジの色が自動で変化
完了（緑） 24時間以内（黄） 期限超過（赤） 通常（グレー）

説明メモ

  • 見出し、箇条書き、表、色付きの注意書きボックスを使って見やすく整理
  • 上部のツールバーからワンクリックで文字装飾を挿入

3. キーボードショートカット

画面上で ? キーを押すと一覧を表示

ボード画面での操作

キー 動作
C または N 選択中のリスト（未選択時は左端のリスト）でカード追加を開始
1 〜 9 左から 1〜9 番目のリストを指定してカード追加を開始
← → / ↑ ↓ リストおよびカードの選択移動
Enter または Space 選択中のカードの詳細を開く

カード作成フォーム入力中

キー 動作
Enter カードを保存し、続けて次のカードを入力（連続作成）
Ctrl + Enter カードを保存して入力欄を閉じる

Esc 入力をキャンセルして閉じる

カード詳細画面での操作

T または - チェックリストを追加
C カードの複製メニューを開く
A カードをアーカイブへ移動

5. 安全な削除・バックアップ・画面の終了

2段階の安全な削除

  • カードを削除すると、まずは画面上部の「アーカイブ」に保管されます
  • 「アーカイブ」画面からいつでも元のリストへ復元できます
  • 完全に消去したい場合のみ、「アーカイブ」内で「完全削除」を実行します

バックアップと引き継ぎ

  • 1日1回、起動時に自動でバックアップを作成（最新7日分を自動保持）
  • 画面上部の「データ管理」→「外部ファイルへ保存」で、画像を含む全データを1つのファイル（.localban）に保存可能
  • 別のパソコンへ移行する際は「外部ファイルから復元」でファイルを読み込むだけで完了します

閉じる（×）ボタンの動作

  • 画面上部の「×: トレイ格納 / ×: 完全終了」ボタンで動作を切り替えられます
  • 「トレイ格納」時は、右上の「×」を押すと画面右下の通知領域（タスクトレイ）に格納され、アイコンクリックですぐに再表示できます
  • アプリを完全に終了する場合は、画面右上の「終了」ボタンを押してください
