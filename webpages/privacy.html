プライバシーポリシー / Privacy Policy

日本語 (Japanese)

1. 基本方針

LocalBan（以下「本アプリ」）は、利用者のプライバシー保護とデータの自己管理を最優先に設計された、完全オフライン動作の個人用タスク管理アプリケーションです。

2. 個人情報の収集・外部送信について

本アプリは、利用者の個人情報、利用履歴、作成したタスク・カード内容、添付画像、クラッシュレポート、統計データ、または端末識別情報を一切収集・記録・外部送信しません。

  • 外部ネットワーク通信なし: 本アプリには外部サーバーへの通信機能、アクセス解析ツール、広告配信モジュール、追跡機能は一切組み込まれていません。
  • アカウント登録不要: ユーザー登録やログインを行うことなく、すべての機能をパソコン内のローカル環境のみでご利用いただけます。

3. データの保存場所と管理

本アプリで作成・編集されたすべてのデータ（ボード、リスト、カード、ラベル、チェックリスト、添付画像、バックアップ、アプリ設定、動作ログ）は、お使いの Windows パソコン内のローカルストレージにのみ保存されます。

  • 通常版（ポータブル版 / インストーラー版）: %APPDATA%\LocalBan\（C:\Users\<ユーザー名>\AppData\Roaming\LocalBan\）配下に保存されます。
  • Microsoft Store 版: Windows のアプリ隔離機能により、パッケージ専用領域（%LOCALAPPDATA%\Packages\zyanpoyo.LocalBan_jcb2ksg0pnr1p\LocalCache\Roaming\LocalBan\）配下に保存されます。
  • 保存されたデータへのアクセス権限はお使いのパソコンのユーザーアカウントに限定され、開発者や第三者がアクセスすることは不可能です。

4. データの削除方法

利用者はご自身のデータを以下の方法でいつでも完全に消去できます。

  • アプリ内からの個別削除: 画面上部の「アーカイブ」から対象カードの「完全削除」を実行すると、カード情報および添付画像ファイルがパソコンから消去されます。
  • Microsoft Store 版の全データ削除: Windows の「設定」→「アプリ」→「インストールされているアプリ」から LocalBan をアンインストールすると、OS の標準機能により保存データも一括で消去されます。
  • 通常版の全データ削除: 同梱の uninstall.bat を実行するか、%APPDATA%\LocalBan\ フォルダーを削除することで全データを消去できます。

5. 免責事項・知的財産権について

  • 非提携について: 本アプリは独立した個人開発プロジェクトであり、いかなる特定の第三者企業、法人、または既存のタスク管理製品・クラウドサービスとも提携、協賛、承認、または関連関係にありません。

本プライバシーポリシーや本アプリに関するお問い合わせは、Microsoft Store の本アプリ掲載ページ内サポート窓口よりご連絡ください。

English

1. Overview

LocalBan ("the Application") is a completely offline, local-first personal Kanban board application for Windows, designed with user privacy and data ownership as its highest priorities.

2. Zero Data Collection & No Telemetry

The Application does not collect, store, transmit, or share any personal information, usage analytics, task contents, attachments, crash reports, telemetry, or device identifiers.

  • No External Network Communication: The Application contains no external server communication code, analytics SDKs, advertising modules, or tracking mechanisms.
  • No Account Required: All features operate strictly offline on your local device without requiring user registration or authentication.

3. Local Data Storage

All data created or managed within the Application (boards, lists, cards, labels, checklists, image attachments, backups, application settings, and logs) is stored exclusively on your local Windows device:

  • Standalone / Installer Edition: Stored under %APPDATA%\LocalBan\ (C:\Users\<Username>\AppData\Roaming\LocalBan\).
  • Microsoft Store Edition: Isolated under the Windows package cache directory (%LOCALAPPDATA%\Packages\zyanpoyo.LocalBan_jcb2ksg0pnr1p\LocalCache\Roaming\LocalBan\).
  • Neither the developer nor any third party has access to your local data.

4. Data Deletion

You retain full control over your data at all times:

  • Within the Application: Permanently delete archived cards via the Archive screen.
  • Microsoft Store Edition: Uninstalling the app via Windows Settings ("Installed apps") automatically removes the entire package data directory.
  • Standalone / Installer Edition: Run uninstall.bat or delete the %APPDATA%\LocalBan\ directory in File Explorer.

5. Disclaimer

  • Non-Affiliation: The Application is an independent project and is not affiliated with, endorsed by, or connected to any third-party company or cloud task management service.
  • Provided "AS IS": The Application is provided "AS IS" without warranty of any kind. In no event shall the developer be liable for any damages or data loss arising from the use of the Application.

6. Contact

For questions regarding this Privacy Policy or the Application, please contact us through the support contact listed on the Microsoft Store product page.
