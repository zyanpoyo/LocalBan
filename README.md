# LocalBan (ローカルバン)

Trello に着想を得た、軽量でオフラインファーストな Windows 11 向けの個人用カンバンボードです。  
外部通信なし・ユーザー認証なしで完全オフライン動作し、単一の `LocalBan.exe` をダブルクリックするだけで直ちに利用可能です。

---

## 🌟 主な特徴

- **完全ローカル・オフライン完結**:
  - すべてのデータは `%APPDATA%\LocalBan` 内の SQLite データベースおよびローカルフォルダに安全に保存されます。
  - 外部CDNやテレメトリ通信は一切行いません。
- **直感的なカンバン操作**:
  - リストおよびカードの滑らかなドラッグ＆ドロップ（並び替え・リスト間移動）。
  - Fractional Indexing による高速並び替え（精度が狭まった際の自動リバランス機能付き）。
- **強力なカード詳細機能**:
  - **画像添付 & カバー画像**: ドラッグ＆ドロップ、ファイル選択、および **クリップボードからの直接貼り付け（Ctrl+V）** に対応。カード上部にサムネイルを表示するカバー画像設定や拡大ライトボックス表示。
  - **GFM準拠 Markdown 説明文**: 見出し、箇条書き、タスクリスト、テーブル、コードブロックに対応。「編集モード」と「プレビューモード」のリアルタイム切替。生HTML無効化によりXSS防止。
  - **チェックリスト**: 複数チェックリストの作成、完了チェック、進捗パーセントバー。
  - **期限（Due Date）**: 日時ピッカーと4色の視覚的期限バッジ（緑=完了、赤=期限超過、黄/オレンジ=24時間以内、グレー=通常）。
  - **カード複製（コピー）**: タイトル「のコピー」、説明・ラベル・チェックリスト・添付ファイル実体を丸ごと新規複製し元カード直下に配置。
- **安全な2段階削除フロー**:
  - 通常画面からは「アーカイブ」のみ可能（誤削除を防止）。
  - リスト削除時も所属カードは自動的にアーカイブに退避。
  - 「アーカイブ一覧」モーダルから明示的に操作した場合のみ、DBおよびディスク上の実体ファイルを物理削除。
- **リアルタイム保存状態インジケーター**:
  - ヘッダーに「✓ 保存済み」「⟳ 保存中...」「⚠ 保存エラー」を常時表示。
- **複数ブラウザタブ間の自動同期**:
  - Web標準の `BroadcastChannel` API により、同一ブラウザ内の別タブで行われた操作がリロードなしでリアルタイム反映。
- **セキュリティ & システム堅牢化**:
  - `127.0.0.1` 固定バインド、Host/Originヘッダー検証、起動時ランダムトークン（`X-LocalBan-Token`）によるCSRF・DNS Rebinding対策。
  - パストラバーサル防止、添付ファイルUUID管理、`X-Content-Type-Options: nosniff`。
  - 多重起動防止（2回目以降のクリック時は既存のブラウザタブを再表示して新プロセスは即座に終了）。
  - 起動時の日次自動バックアップ（最新7世代保持）。

## 🚀 起動方法

1. `dist/LocalBan.exe` をダブルクリックして実行します。
2. バックグラウンドでローカルサーバーが起動し、OS既定のブラウザが自動的に開いてアプリが立ち上がります。
3. Windowsのタスクトレイに「LocalBan」アイコンが常駐します。

> [!NOTE]
> 初回起動時に Windows SmartScreen の「WindowsによってPCが保護されました」と表示された場合は、「詳細情報」をクリックし「実行」を選択してください（個人開発の未署名バイナリであるためです）。

---

## 🛑 アプリの終了方法

以下のいずれかの方法で安全に終了できます：

1. **画面から終了**:
   - Web画面右上の「**終了**」ボタンをクリック → 確認ダイアログで「終了する」を選択。
2. **タスクトレイから終了**:
   - 画面右下のタスクトレイ内「LocalBan」アイコンを右クリック → 「**終了**」を選択。

---

## 🗑️ アンインストール方法

セキュリティおよび誤操作によるデータ喪失防止のため、**Web画面からのアンインストールは行えません**。  
アンインストールする場合は、配布ZIPに同梱されているアンインストールバッチを実行してください：

1. 本アプリのフォルダ内にある `uninstall.bat` をダブルクリックします。
2. 確認ダイアログ「LocalBan をアンインストールしますか？」が表示されますので、「はい」を選択します。
3. 実行中の LocalBan プロセスが安全に停止され、保存データ（`%APPDATA%\LocalBan`）および本体プログラム（`LocalBan.exe`）が完全に削除されます。
4. 完了ダイアログが表示されたら、残ったフォルダをごみ箱へ移動して削除してください。

---

## 📁 データの保存場所

すべてのデータは以下のローカルパスに保存されます：

- **データベース**: `%APPDATA%\LocalBan\localban.db` (SQLite WALモード)
- **添付ファイル**: `%APPDATA%\LocalBan\attachments\`
- **日次バックアップ**: `%APPDATA%\LocalBan\backups\` (最新7世代保持)
- **ログ**: `%APPDATA%\LocalBan\logs\app.log`

## 🛠️ 開発・ビルド手順（開発者向け）

### 必要環境
- Python 3.13 (`uv` 推奨)
- Node.js v22+

### 依存関係インストール
```bash
# Python仮想環境の構築 (uv)
uv venv .venv
uv pip install -e . --extra dev

# フロントエンド依存関係 (npm)
cd frontend
npm install
cd ..
```

### テスト実行
```bash
.venv\Scripts\python -m pytest tests/test_backend.py -v
```

### 単一exeのビルド
```bash
.venv\Scripts\python build_exe.py
```
ビルドが完了すると、`dist/LocalBan.exe` に単一の実行可能バイナリが生成されます。
