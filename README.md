# LocalBan (ローカルバン) v2.0.0

軽量で直感的に操作できる、完全オフライン動作の Windows 11 向け個人用カンバンボードです。  
**Tauri v2 (Full Rust)** による独立したネイティブデスクトップクライアントアプリとして動作し、外部通信なし・ユーザー認証なしで完全オフライン動作。単一の `LocalBan.exe` をダブルクリックするだけで直ちに利用可能です。

---

## 🌟 主な特徴

- **完全ネイティブ・オフライン完結 (Tauri v2 + Full Rust)**:
  - バックエンド処理・SQLite 操作・画像配信をすべて **Rust** で完結。爆速な起動と省メモリを実現。
  - すべてのデータは `%APPDATA%\LocalBan` 内の SQLite データベースおよびローカルフォルダに安全に保存されます。
  - 外部通信やテレメトリ送信は一切行いません。
- **独立デスクトップウィンドウ & タスクトレイ常駐**:
  - Webブラウザのタブではなく、独立したネイティブクライアントウィンドウ（Microsoft Edge WebView2）として起動。
  - ウィンドウ右上の「×（閉じる）」ボタンを押すとタスクトレイ（通知領域）に格納され、トレイアイコンのクリックや `LocalBan.exe` の再実行ですぐに最前面へ復元。
- **直感的なカンバン操作 & フルキーボード対応**:
  - リストおよびカードの滑らかなドラッグ＆ドロップ（並び替え・リスト間移動）。
  - Fractional Indexing による高速並び替え（精度が狭まった際の自動リバランス機能付き）。
  - **キーボード完結の操作体系**: `c` / `n` / `1〜9` でのカード作成開始、`Enter`（連続作成）、`Ctrl+Enter`（保存完了）、`Shift+Enter`（保存してそのまま詳細展開）、矢印キーでのリスト・カード選択移動（自動スクロール追従）、`?` キーでのショートカット一覧ヘルプ表示に対応（日本語IME変換ガード付き）。
- **強力なカード詳細機能**:
  - **画像添付 & カバー画像**: ドラッグ＆ドロップ、ファイル選択、および **クリップボードからの直接貼り付け（Ctrl+V）** に対応。カード上部にサムネイルを表示するカバー画像設定や拡大ライトボックス表示。
  - **GFM準拠 Markdown 説明文**: 見出し、箇条書き、タスクリスト、テーブル、コードブロックに加え、**Qiita互換のノート記法（`:::note info` / `warn` / `alert`）**に対応。**キーボードショートカット（Ctrl+Shift+P によるプレビュー切替、Ctrl+Enter による保存、フォーマット装飾）**・ツールバー・ヘルプポップオーバーを備え、快適な編集・プレビューが可能。生HTML無効化によりXSS防止。
  - **クイックキーバインド**: 詳細モーダル内で `e`（説明編集）、`d`（期限）、`t`/`-`（チェックリスト）、`c`（複製）、`a`（アーカイブ）などのショートカット操作に対応。
  - **チェックリスト**: 複数チェックリストの作成、完了チェック、進捗パーセントバー。
  - **期限（Due Date）**: 日時ピッカーと4色の視覚的期限バッジ（緑=完了、赤=期限超過、黄/オレンジ=24時間以内、グレー=通常）。
  - **カード複製（コピー）**: タイトル「のコピー」、説明・ラベル・チェックリスト・添付ファイル実体を丸ごと新規複製し元カード直下に配置。
- **安全な2段階削除フロー**:
  - 通常画面からは「アーカイブ」のみ可能（誤削除を防止）。
  - リスト削除時も所属カードは自動的にアーカイブに退避。
  - 「アーカイブ一覧」モーダルから明示的に操作した場合のみ、DBおよびディスク上の実体ファイルを物理削除。
- **リアルタイム保存状態インジケーター**:
  - ヘッダーに「✓ 保存済み」「⟳ 保存中...」「⚠ 保存エラー」を常時表示。
- **セキュリティ & システム堅牢化**:
  - Tauri ネイティブ IPC サンドボックス境界により、外部ネットワークからの直接リクエストを根本遮断。
  - パストラバーサル防止、添付ファイルUUID管理、`X-Content-Type-Options: nosniff`。
  - 単一インスタンス制御（2回目以降のクリック時は既存ウィンドウを前面化）。
  - 起動時の日次自動オンラインバックアップ（最新7世代保持）。

## 🚀 起動・インストール方法

お好みに応じて **ポータブル版** または **インストール版** のいずれかをご利用いただけます。

- **ポータブル版（インストール不要）**:
  1. [`dist/LocalBan.exe`](file:///c:/Users/ymasa/MyProject/LocalBan/dist/LocalBan.exe) をダブルクリックして実行します。
  2. 独立したデスクトップウィンドウ（LocalBan）が即座に立ち上がります。
- **インストール版（スタートメニュー・ショートカット登録）**:
  1. [`dist/LocalBan-v2.0.0-setup.exe`](file:///c:/Users/ymasa/MyProject/LocalBan/dist/LocalBan-v2.0.0-setup.exe) を実行してセットアップします。
  2. デスクトップおよびスタートメニューにショートカットが登録され、Windows の「アプリと機能」からアンインストールも可能になります。

> [!NOTE]
> 初回起動時に Windows SmartScreen の「WindowsによってPCが保護されました」と表示された場合は、「詳細情報」をクリックし「実行」を選択してください（個人開発の未署名バイナリであるためです）。

## 🛑 ウィンドウの最小化と終了方法

- **閉じる（×）ボタンの挙動切り替え**:
  - ヘッダー右上のトグルボタン（`×: トレイ格納` / `×: 完全終了`）をクリックすることで、ウィンドウ右上の「**×**」ボタンを押した際の動作をいつでも切り替えられます（設定は `%APPDATA%\LocalBan\settings.json` に自動保存されます）。
- **タスクトレイへの格納（デフォルト）**:
  - `×: トレイ格納` モード時は、ウィンドウ右上の「**×**」ボタンを押すとプロセスは終了せずタスクトレイに格納されます。
  - トレイアイコンをクリックするか、`LocalBan.exe` を再度ダブルクリックすることで、いつでも一瞬で画面が最前面に復帰します。
- **アプリの完全終了**:
  - **×ボタンから終了**: ヘッダーで `×: 完全終了` モードに切り替えた状態でウィンドウ右上の「**×**」ボタンをクリック。
  - **画面ボタンから終了**: アプリ画面右上の「**終了**」ボタンをクリック → 確認ダイアログで「終了する」を選択。
  - **タスクトレイから終了**: タスクトレイ内「LocalBan」アイコンを右クリック → 「**終了**」を選択。

## 🗑️ アンインストール方法

セキュリティおよび誤操作によるデータ喪失防止のため、**画面内からのアンインストール操作は配置していません**。  
アンインストールする場合は、ご利用の形態に応じて以下の手順を実行してください：

- **Microsoft Store 版 / インストーラー版の場合**:
  - Windows の「設定」→「アプリ」→「インストールされているアプリ」から「LocalBan」を選択し、「アンインストール」を実行します。
- **ポータブル版（配布ZIP）の場合**:
  1. 本アプリのフォルダ内にある `uninstall.bat` をダブルクリックします。
  2. 確認ダイアログ「LocalBan をアンインストールしますか？」が表示されますので、「はい」を選択します。
  3. 実行中の LocalBan プロセスが安全に停止され、保存データ（`%APPDATA%\LocalBan`）および本体プログラム（`LocalBan.exe`）が完全に削除されます。
  4. 完了ダイアログが表示されたら、残ったフォルダをごみ箱へ移動して削除してください。

## 📁 データの保存場所

すべてのデータは以下のローカルパスに保存されます：

- **データベース**: `%APPDATA%\LocalBan\localban.db` (SQLite WALモード)
- **アプリ設定**: `%APPDATA%\LocalBan\settings.json`
- **添付ファイル**: `%APPDATA%\LocalBan\attachments\`
- **日次バックアップ**: `%APPDATA%\LocalBan\backups\` (最新7世代保持)
- **ログ**: `%APPDATA%\LocalBan\logs\app.log`

## 🛠️ 開発・ビルド手順（開発者向け）

### 必要環境
- **Rust** (1.78+ / `stable-x86_64-pc-windows-msvc`)
- **Visual Studio 2022 C++ Build Tools** (MSVC)
- **Windows 10/11 SDK** (`makeappx.exe` - MSIX パッケージ作成時)
- **Node.js** (v20+ / npm v10+)

### 依存関係セットアップ
```bash
# フロントエンド依存関係のインストール
cd frontend
npm install
cd ..
```

### バックエンド単体・結合テストの実行
```bash
cd src-tauri
cargo test
cd ..
```

### 単一exeのビルド & 配布パッケージ作成
```bash
node scripts/build_dist.js
```
ビルドが完了すると、`dist/LocalBan.exe` および `dist/LocalBan-v2.0.0-windows.zip` が生成されます。

### Microsoft Store 提出用 MSIX パッケージのビルド
```bash
node scripts/build_msix.js
```
ビルドが完了すると、`dist/LocalBan-v2.0.0-x64.msix` が生成されます。
